У цьому проекті ми практикуємо Git і не тільки. Це розраховано на подальшу роботу вже з проектом, який піде на МАН.

Щоб створити .venv потрібно ввести команди: py -m venv .venv, а після - .\\.venv\\Scripts\\Activate.ps1

Залежності вказані у requirements.txt, тобто зайти в цей файл і вписати, які бібліотеки потрібні(за допомогою: pip install -r requirements.txt

).



Запустити командою: python src\_main.py

Цей проект створює віртуальне середовище, коміт, має залежності с requirements.txt.
